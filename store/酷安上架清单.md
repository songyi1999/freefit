## 四、应用描述文案（提交时复制）

**一句话简介（32字内）：**
完全离线的免费健身App：AI姿态纠错、定制计划、GPS跑步轨迹，数据只存本机。

**完整描述：**
自由炼（FreeFit）—— 自律给我自由。

一款完全离线、无账号、无服务器的健身应用，你的所有数据只保存在自己手机里，不上传、不跟踪、无广告。

【AI 实时纠错】手机摄像头识别运动姿态，全程在本机处理（不上传画面），支持深蹲、俯卧撑、卷腹、开合跳、哑铃系列等 16 个动作的自动计数与纠错；跟练时可开右下角小窗，边看示范边纠错。

【智能定制计划】回答几个问题（性别/年龄/器械/伤病/目标），自动生成专属计划；有伤病自动规避相关动作，动作可替换可调整。

【户外跑步】GPS 记录轨迹与配速，高德底图展示，一键生成战绩卡片分享朋友圈。

【跟练训练】骨架小人动画领练 + 语音倒计时 + 提示音，16 个动作（含哑铃），内置新手/核心/燃脂计划。

【应用内更新】新版本自动提醒，应用内下载安装。

支持中英双语（跟随系统语言）。开源：github.com/songyi1999/freefit

## 五、需要你自己完成的步骤

1. **注册酷安开发者**：https://developer.coolapk.com → 个人开发者认证（身份证 + 人脸，免费）
2. **开启 GitHub Pages**（隐私政策 URL 生效）：仓库 Settings → Pages → Branch 选 main、目录选 /docs → Save
3. **创建应用**：填基础信息（第一节）+ 签名信息（第二节，备案环节用）+ 隐私政策 URL（第三节）
4. **发起 APP 备案**：酷安后台会引导提交工信部备案（免费，1~2 周；个人备案需要身份证信息，无需软著）
5. **上传 APK**：用 v0.9.3 的 `FreeFit-release.apk`（Releases 页下载，CI 产出即签名包）
6. **传截图**：3~5 张手机截图（建议：首页、跟练播放器+AI小窗、跑步轨迹地图、分享卡片）—— 真机截图即可
7. **传图标**：`store/icon-512.png`（已生成）
8. 提审（酷安一般 1~3 个工作日）
