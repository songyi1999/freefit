# 应用分发渠道方案（2026-10 更新）

> 背景：酷安新开发者注册已关闭（2026-10 实测），国内正规商店对个人开发者全部关闭或要求软著。
> **现行方案：GitHub Releases（OTA）+ 蒲公英（国内下载页）+ APKPure（海外商店式分发）**

## 渠道一：蒲公英 PGYER（国内分发主渠道）

**定位**：应用托管分发平台 —— 生成稳定的下载页链接 + 二维码，朋友扫码即装，替代"传 APK 文件"。
免费额度：上传不限量、下载不限次，个人需实名认证。**不需要软著、不需要备案**（平台定位为内测分发）。

**步骤（约 10 分钟）：**
1. 注册 https://www.pgyer.com（手机号/邮箱 + 个人实名）
2. 「应用」→「发布新应用」→ 上传 `FreeFit-release.apk`（用 GitHub Releases v0.9.3 的包）
3. 填应用信息：名称「自由炼」、简介、分类「健康健身」、上传 `store/icon-512.png`
4. 应用设置保持默认即可
5. 生成**应用短链**（如 pgyer.com/xxxx），发群里或印二维码，扫码 → 下载 → 安装

**注意**：蒲公英下载页免费版有开屏广告页（平台行为，无法关闭）；应用内的 GitHub OTA 更新不受影响，两者并存。

## 渠道二：APKPure（海外 + 国内可访问的"商店"）

**定位**：真正的应用目录（有搜索、有详情页、有自动更新推送），国内不翻墙一般也能访问。
完全免费上传，不要软著，注册开放。

**步骤（约 10 分钟）：**
1. 打开 https://apkpure.com/cn/submit-apk
2. 注册/登录（邮箱即可）
3. 上传 APK + 填应用信息（名称/简介/分类/图标，用下方文案）
4. 审核 1~3 天，通过后应用出现在 APKPure 目录，用户可搜索"FreeFit"或"自由炼"

## 渠道三：GitHub Releases + 应用内 OTA（已有，不动）

现有用户的更新主通道，保持不变。

## 完整应用描述（提交时复制）

自由炼（FreeFit）—— 自律给我自由。

一款完全离线、无账号、无服务器的健身应用，你的所有数据只保存在自己手机里，不上传、不跟踪、无广告。

【AI 实时纠错】手机摄像头识别运动姿态，全程在本机处理（不上传画面），支持深蹲、俯卧撑、卷腹、开合跳、哑铃系列等 16 个动作的自动计数与纠错；跟练时可开右下角小窗，边看示范边纠错。

【智能定制计划】回答几个问题（性别/年龄/器械/伤病/目标），自动生成专属计划；有伤病自动规避相关动作，动作可替换可调整。

【户外跑步】GPS 记录轨迹与配速，高德底图展示，一键生成战绩卡片分享朋友圈。

【跟练训练】骨架小人动画领练 + 语音倒计时 + 提示音，16 个动作（含哑铃），内置新手/核心/燃脂计划。

【应用内更新】新版本自动提醒，应用内下载安装。

支持中英双语（跟随系统语言）。开源：github.com/songyi1999/freefit
