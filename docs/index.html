自由炼（FreeFit）隐私政策

生效日期：2026年10月24日 · 本政策适用于 Android 客户端（包名 com.freefit.app）

一、我们的核心原则

自由炼是一款完全离线、无账号、无服务器的健身应用。您的全部个人数据仅保存在您自己的手机本地，我们没有任何服务器可以接收、存储或处理您的数据。

二、数据的存储位置

以下数据仅写入本机（应用私有数据库/存储），卸载应用即彻底删除，我们无法也从不接触：

数据用途存储方式
训练记录展示历史训练、打卡统计本机数据库
跑步轨迹/距离/配速轨迹回显、成绩统计与分享卡片本机数据库
个人资料（性别/年龄/器械/伤病）生成定制训练计划本机偏好存储
定制训练计划保存您生成的计划本机偏好存储

三、权限用途说明

权限使用场景数据处理方式
相机您主动开启「AI 姿态识别」时识别运动姿态相机画面实时在本机处理，不拍照、不录像、不缓存、不上传
定位您主动开始「户外跑步」时记录轨迹坐标仅存本机，不上传
网络加载地图瓦片、检查应用更新仅与地图瓦片服务及 GitHub 通信，不携带个人数据
通知跑步记录前台服务常驻提示（Android 系统要求）—
安装未知应用您主动确认「立即安装」应用内更新包时—

所有敏感权限（相机/定位）均在您主动使用对应功能时才发起申请，您可以随时在系统设置中拒绝或撤销。

四、第三方服务

本应用不集成任何统计、广告、推送或账号 SDK。仅涉及：

  • 高德地图瓦片：跑步地图底图。瓦片服务仅获取地图图片，我们不会向其发送您的位置（瓦片按区域加载，不含个人标识）。
  • GitHub：检查版本更新与下载安装包。请求中仅包含版本号查询，不含任何个人信息。

五、未成年人保护

本应用不面向 14 岁以下儿童，不收集任何未成年人的个人信息。

六、健康与安全声明

本应用提供的训练内容为通用健身建议，不构成医疗建议。如有伤病或心血管等疾病，请在医生指导下锻炼。应用内的伤病规避选项仅为辅助，请根据自身情况量力而行。

七、政策更新

如政策有重大变更，我们将在应用内提示。继续使用视为您同意更新后的政策。
